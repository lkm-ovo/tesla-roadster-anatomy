# Tesla Roadster 技术解剖

[在线体验](https://lkm-ovo.github.io/tesla-roadster-anatomy/)

深色主题、中文标注的交互式技术解剖。打开页面即可使用，无需安装依赖。

- 三电机布局、底部电池包与 SpaceX 冷气推进选装概念。
- 可切换爆炸视图、调节分解程度，并放大查看局部。
- 飞行动画与解剖视图共用原 Roadster 模型，保留车身、轮毂、座舱与电池细节。
- 约 11.8 秒的参考动作：离台、调平、喷气下降、着地散雾、驶离；支持暂停和重播。
- 支持手机、键盘操作及减少动态效果设置。

键盘：`E` 切换爆炸视图，`1 / 2 / 3` 选择系统，`Esc` 重置。

## 运行

在线访问上方链接，或下载本仓库并打开 `index.html`。页面的绘图、样式、数据和交互脚本均内嵌在同一文件中，不需要构建。

## 示意范围

以 2017 年 Roadster 概念架构及 2018 年 SpaceX 冷气推进选装提议为参考。图中 3,072 个电芯、模组排布、十处喷口的坐标和安装结构为讲解用重建；飞行为参考动作示意。资料入口保存在页面的“资料与示意范围”中。

使用 Anatomy 绘图工具制作，按仓库内 MIT 许可证分发。
